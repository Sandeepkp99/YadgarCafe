# ☕ YadgarCafe

Restaurant Management System built using:

- ASP.NET Core 8 Web API
- React + Vite
- PostgreSQL
- Entity Framework Core
- JWT Authentication
- Clean Architecture

## Modules

- Authentication
- Customer
- Staff
- Admin
- Product Management
- Inventory
- Orders
- Billing
- Dashboard
- Reports

## Architecture

- Clean Architecture
- Repository Pattern
- Unit of Work
- JWT Authentication
- Role Based Authorization
