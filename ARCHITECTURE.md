## State Management Flow

```
AuthContext
    ?
    ??? Initial Load
    ?   ??? Check localStorage for token
    ?   ??? Decode JWT (get user info)
    ?   ??? Set user state
    ?   ??? setIsLoading(false)
    ?
    ??? Login Action
    ?   ??? authService.login()
    ?   ??? Store tokens
    ?   ??? Parse JWT
    ?   ??? setUser(userData)
    ?   ??? Navigate to /dashboard
    ?
    ??? Protected Routes Check
    ?   ??? ProtectedRoute Component
    ?   ??? Check isAuthenticated
    ?   ??? If true ? Render Page
    ?   ??? If false ? Redirect to /login
    ?
    ??? Logout Action
    ?   ??? Clear localStorage
    ?   ??? setUser(null)
    ?   ??? Navigate to /login
    ?   ??? API interceptor removes token
    ?
    ??? Token Refresh
        ??? API returns 401
        ??? Axios Interceptor catches
        ??? POST /auth/refresh-token
        ??? Receive new accessToken
        ??? Update localStorage
        ??? Retry original request
```
